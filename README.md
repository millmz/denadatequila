# De Nada Tequila — Website

Source code for [denadatequila.com](https://denadatequila.com), a static site hosted on Netlify.

## Pages

- `index.html` — Home
- `our-story.html` — Our Story
- `cocktails.html` — Cocktails
- `shop.html` — Shop
- `faq.html` — FAQ
- `welcome.html` — Welcome
- `privacy.html` / `terms.html` — Legal

## Deployment

The site deploys as-is (no build step). `_redirects` contains the Netlify redirect rules.
